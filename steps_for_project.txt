8. Feature Selection based on data distribution

| **Action**                        | **Feature Property**       | **Reason**                                               |
| --------------------------------- | -------------------------- | -------------------------------------------------------- |
| Remove constant / quasi-constant  | No variability             | Feature is useless for learning—adds no information.     |
| Transform skewed features         | Highly skewed distribution | Improves model performance and normality assumptions.    |
| Remove highly correlated features | Multicollinearity          | Avoids redundancy and instability in model coefficients. |
| Remove high-cardinality features  | Too many unique categories | Risks overfitting and poor generalization.               |
| Remove low-variance categorical   | Non-informative            | Offers little to no predictive value.                    |




============================================================================================
9. Outlier treatment: (Reduced risk of model bias, Better performance on downstream tasks)

| **Method**                        | **Description**                                                              | **When to Use**                                     |
| --------------------------------- | ---------------------------------------------------------------------------- | --------------------------------------------------- |
| **Capping (Winsorization)**       | Replaces extreme values with nearest acceptable boundaries (e.g., IQR-based) | When you want to retain data and control distortion |
| **Z-score Filtering**             | Removes rows where any column has a Z-score > 3                              | When data is approximately normally distributed     |
| **Log / Power Transform**         | Reduces skewness and compresses outliers (e.g., Yeo-Johnson, Box-Cox)        | When features are positively skewed or heavy-tailed |
| **Model-Based (IsolationForest)** | Identifies and removes anomalies based on data patterns and isolation scores | When there’s no clear distribution or threshold     |


============================================================================================
10. Missing Values treatment:

========================================================================================================================================================================================
| **Type**                                | **Meaning**                                                                  |
| --------------------------------------- | ---------------------------------------------------------------------------- |
| **MCAR** (Missing Completely at Random) | Missing values have no pattern; safe to drop or impute                       |
| **MAR** (Missing at Random)             | Missingness depends on observed data (e.g., income missing for certain jobs) |
| **MNAR** (Missing Not at Random)        | Missingness is due to unobserved factors (e.g., patients hiding weight)      |

============================================================================================

| **Method**                 | **When to Use**                                              | **Code**                         |
| -------------------------- | ------------------------------------------------------------ | -------------------------------- |
| **Mean / Median**          | - MCAR or MAR<br>- Use mean for symmetric, median for skewed | `SimpleImputer(strategy='mean')` |
| **KNN Imputation**         | MAR, small to medium datasets, similar samples               | `KNNImputer()`                   |
| **Model-Based Imputation** | MAR or MNAR with clear feature relationships                 | Use regression/classifier models |
| **Drop Column**            | >50% missing and not critical                                | `df.drop(columns=[...])`         |
| **Leave As-Is**            | When using models that handle `NaN` natively                 | e.g., CatBoost                   |

============================================================================================

| **Method**               | **When to Use**                                       | **Code**                                  |
| ------------------------ | ----------------------------------------------------- | ----------------------------------------- |
| **Mode (Most Frequent)** | MCAR or MAR                                           | `SimpleImputer(strategy='most_frequent')` |
| **'Missing' Category**   | When missing values carry potential meaning           | `df[col].fillna("Missing")`               |
| **Drop if Useless**      | Too many missing values and feature is low-importance | `df.drop(columns=[...])`                  |

12. Statistical correlation analysis (Feature Selection):


(Statistical Tests for Correlation (Based on Feature and Target Type))

| **Feature Type** | **Target Type** | **Recommended Test**                        | **Purpose**                                                  |
| ---------------- | --------------- | ------------------------------------------- | ------------------------------------------------------------ |
| Numerical        | Numerical       | **Pearson** / **Spearman Correlation**      | Assess linear or monotonic relationship                      |
| Categorical      | Categorical     | **Chi-Square Test**                         | Test association strength between categories                 |
| Numerical        | Categorical     | **ANOVA F-test** / **Mutual Information**   | Evaluate group mean differences                              |
| Categorical      | Numerical       | **Point Biserial** / **Mutual Information** | Assess correlation between binary class and numeric variable |
